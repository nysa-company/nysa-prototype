Mortgage underwriting macro process

TypeMacro process
Verified byJavier Aldape · Jun 20
Owner—
Verify
View history
Archive
Verified
Last edited Jun 20

1. Application intake

Borrower submits the application and initial documents through the broker portal. Loan file intake checks the file against the completeness checklist ("expediente completo") before it moves forward; incomplete files are returned to the broker with the missing items flagged.

2. Underwriting review

Underwriting scores the file and verifies income, credit, and property documentation. The minimum file score to proceed is 80 (raised from 75 on Jun 20). Files below the threshold are sent back for additional documentation or declined.

3. Approval & funding

Approved files move to final sign-off and funding. Data-sharing clauses in any partner-originated file are checked against the data-sharing redline review checklist before funds are released.

4. Ongoing controls

Two controls monitor this process day to day: the expediente completo check (daily, currently stale — past its 60-day verification window) and the data-sharing redline review checklist (verified). Both are reviewed in the weekly partner sync.
